# 三维角度记录器实现方案

## 1. 功能定位

新增独立应用 `AngleRecorder`，入口位于 LuckyWheel 后、Setup 前。沿用项目现有的 C++、Mooncake、LVGL 和 HAL 架构。

用户先设置记录时长，再通过 A 键开始记录。记录期间支持暂停、继续和累计阶段快照；结束后查看各阶段的三轴角度曲线及最大值、最小值。

## 2. 页面与操作流程

### 2.1 时长设置页

- 进入应用后先设置时长，不立即开始记录。
- 默认30秒，首版支持10～300秒。
- 通过触屏加减调整，步长10秒。
- 显示设定时长、传感器状态和“A：开始”提示。
- 按 A 后进入静止校准；校准通过后设定起始姿态并开始记录。
- 传感器异常或校准失败时明确提示，不生成无效记录。

### 2.2 记录页

显示当前状态、有效记录时间／设定时长、三轴角度、快照数量和三轴实时曲线。

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| 记录中 | 短按 A | 暂停记录 |
| 记录中 | 短按 B | 保存累计阶段快照，继续记录 |
| 暂停中 | 短按 A | 继续记录 |
| 暂停中 | 长按 B，达到800毫秒 | 结束记录，进入结果页 |
| 记录中 | 达到设定时长 | 自动结束，进入结果页 |
| 设置／校准／记录／暂停／结果中 | 双键长按 | 返回启动器，释放本次记录资源 |

长按 B 只触发一次；双键返回优先于单键操作。记录中长按 B 不生成快照，短按快照需在松开按键并确认未达到长按条件后触发。

### 2.3 结果页

每页对应一个快照或最终结果，包含：

- 阶段名称和记录时长。
- Z、X、Y 三个轴各自的最大角度、最小角度。
- Z、X、Y 三张独立折线图。
- 页码，例如“阶段2／共4页”。

默认展示最终完整记录，左右滑动切换阶段。没有快照时只显示最终结果。

## 3. 时间与暂停规则

横轴使用有效记录时间：

- 暂停期间不累计时间、不保存记录点。
- 暂停后继续，时间从暂停位置接着增长。
- 暂停期间仍更新姿态估计，保证恢复记录时角度有效。
- 起始姿态始终不变，不因暂停或快照重新归零。
- 暂停期间的运动没有记录曲线；恢复后的第一个点标记为新曲线段，避免连线被误认为实际采样过程。

例如设定30秒，中途暂停20秒，最终仍获得30秒有效记录数据。有效记录时间表示记录状态持续时间；传感器读取缺失不延长记录，而是在对应时间位置保留缺口。

## 4. 三轴角度定义

以开始记录时的姿态作为参考，使用加速度计与陀螺仪融合计算四元数，再转换为相对起始姿态的三轴角度。推荐采用六轴 Mahony 算法。

固定采用 Z → Y → X 的欧拉角分解顺序：

| 曲线 | 含义 |
| --- | --- |
| Z | 相对偏航角 |
| X | 相对横滚角 |
| Y | 相对俯仰角 |

角度带正负号，最大值和最小值直接按数值统计。例如某轴从 −20° 到35°，最小值为 −20°，最大值为35°。

计算相对姿态时，先固定四元数的坐标约定，再使用起始姿态的逆与当前姿态相乘。四元数在计算和转换前归一化；三角函数输入需限制在有效范围内。

### 4.1 测量边界

- X、Z 跨越 ±180° 时做连续展开，避免曲线突然跳变。
- Y 接近 ±90° 时，欧拉角存在奇异性，X、Z 无法稳定独立分解。此区间标记为角度分解不可靠，相关曲线断开，不将异常跳值计入极值；四元数姿态估计继续运行。
- 跨越奇异区间后，连续展开不能保证跨区间唯一衔接；重新建立可靠分段，并保留质量标记，不伪造连续旋转轨迹。
- 曲线表示固定分解规则下的姿态角，不能简单理解为三个轴各自累计旋转的圈数。
- BMI270 六轴方案缺少绝对航向参考，航向存在漂移，实际误差通过实机验证确定。
- 运动时根据加速度数据的可信度降低其校正权重，避免把线性加速度直接解释为倾斜。

## 5. 累计阶段快照

快照保存从记录开始到按下 B 时的全部有效阶段数据。

| 操作时刻 | 快照内容 |
| --- | --- |
| 有效时间8秒按 B | 0～8秒曲线及极值 |
| 有效时间17秒按 B | 0～17秒曲线及极值 |
| 有效时间30秒结束 | 0～30秒最终完整结果 |

每个快照冻结：

- 截止有效时间。
- 最后一个已完成采样点的位置。
- 三个轴各自的最大值、最小值。
- 各轴是否包含有效数据，以及阶段内的数据异常标记。

快照不复制整段采样数据。所有阶段引用同一份只追加的记录数组，通过截止位置限定范围。后续采样不会改变已有快照的曲线和极值。

快照命令携带按键事件的有效时间；处理时只纳入时间不晚于该事件的已完成采样点，避免任务调度延迟将后续数据加入快照。

首版最多保存32个快照；达到上限时提示“快照已满”，继续记录，不覆盖旧快照。最终完整结果不占用快照名额。

## 6. 采样、计算与内存

| 项目 | 配置 |
| --- | --- |
| IMU 目标采样频率 | 100 Hz |
| 数据保存频率 | 每个有效采样点均保存 |
| 界面刷新频率 | 10 Hz |
| 最大有效记录时长 | 300秒 |
| 快照容量 | 32个 |
| 数据保存位置 | 内存，退出应用后释放 |

每个采样点保存有效时间、X／Y／Z 角度；恢复记录、读取失败或分解异常通过标记记录。

300秒约有30,000个采样点，仅时间与三轴角度约占480 KB，另加标记、边界点及快照数据。优先使用 PSRAM，开始记录前完成容量分配，避免记录中反复申请内存。

采样调度使用单调时钟与实际时间间隔。延迟后不通过重复旧读数补齐采样点；每个新读数最多用于一次姿态更新。

图表按时间区间抽取极值用于绘制，完整数据保留。统计极值使用有效采样数据，不能使用绘图降采样后的数据。绘图必须保留阶段截止位置、暂停断点和异常缺口。

每张图按真实时间映射横坐标；纵轴覆盖对应阶段的有效角度范围，留出边距。恒定角度使用非零显示范围；没有有效数据的轴显示“无有效数据”，不以0代替极值。

## 7. 项目集成

### 7.1 新增模块

| 位置 | 职责 |
| --- | --- |
| `main/apps/app_angle_recorder/app_angle_recorder.h/.cpp` | 应用生命周期、按键处理、页面切换 |
| `main/apps/app_angle_recorder/model/angle_recorder.h/.cpp` | 记录状态、时间、样本、快照和极值 |
| `main/apps/app_angle_recorder/model/attitude_estimator.h/.cpp` | 零偏校准、姿态融合、相对三轴角度 |
| `main/apps/app_angle_recorder/view/view.h/.cpp` | 时长设置、记录界面、结果图表及滑动切换 |

### 7.2 必要修改

- `main/hal/hal_imu.cpp`：当前配置为 `BOSCH_ACCELEROMETER_ONLY`；核实驱动模式，启用加速度计和陀螺仪，检查读取返回值、量程和单位。
- `main/hal/hal.h`：增加可靠采样接口，提供时间戳、新数据和有效性信息；保留现有接口供 IMU 应用使用。
- 核对现有 IMU 读取中的 X、Y 交换与设备坐标系，确定一致的右手坐标约定后再用于姿态融合。
- `main/apps/apps.h`：引入新应用。
- `main/main.cpp`：在 `AppLuckyWheel` 后注册，在 `AppSetup` 前显示。
- `main/assets`：加入新应用图标。
- 必要时开启 LVGL 图表配置。现有 CMake 递归收集应用源码，新增文件后重新配置构建。

### 7.3 按键与并发

按键复用 `KeyManager`，每轮只更新一次按键状态。长按 B 的识别放在本应用内，不改其他应用的按键行为。

采样与姿态计算由独立任务负责；界面通过受保护的状态副本读取结果。开始、暂停、快照和停止命令由采样任务顺序处理，确保快照截止点与极值一致。

只在操作 LVGL 对象时持有 `LvglLockGuard`，不在锁内读取 IMU 或计算姿态。共享样本只追加，界面只读取已发布的完整前缀。

退出时先通知并等待采样任务停止，再销毁界面和记录数据；同时清除待处理命令及回调，避免访问已释放对象。

## 8. 异常处理

- 初始化失败：禁止开始记录，显示传感器异常。
- 校准期间运动：等待重新稳定，不使用错误零偏；支持双键退出。
- 读取失败／旧数据：不追加有效记录点，不重复积分，曲线标记缺口。
- 采样间隔异常：使用实际时间间隔；严重中断后停止有效记录并提示，不伪造缺失运动。
- 角速度超量程：标记记录质量异常，不将结果当作可靠测量。
- 内存不足：开始前提示失败，不进入记录状态。
- 重复按键：按当前状态校验操作，避免重复停止或重复生成快照。
- 命令队列满：反馈操作未成功，不静默丢弃快照或停止请求。
- 没有有效角度：对应轴显示“无有效数据”，不输出虚假的最大值或最小值。
- 达到截止时间：只纳入时间范围内的样本，冻结最终结果，不追加超时数据。

## 9. 实施与验收顺序

1. 修正并验证 IMU 双传感器采样、单位和设备坐标系。
2. 完成静止校准、四元数融合和相对三轴角度计算。
3. 完成时长设置、记录／暂停／继续／结束状态管理。
4. 加入累计快照和冻结极值。
5. 完成三轴图表、曲线断点和结果滑动切换。
6. 注册应用入口并进行固件编译验证。
7. 实机验证已知角度、跨 ±180°、奇异区间、暂停恢复、阶段快照和异常退出。

验收重点：时间不包含暂停；旧快照不随新数据变化；每页极值与该阶段完整有效数据一致；曲线正确反映采样缺口；记录任务退出后资源完整释放。

首版不加入历史存储、文件导出或联网功能。不新增测试代码，验证采用固件编译与实机检查。
